
# 🍽️ Part-Time Employee Scheduler (1 Week)

เว็บแอปพลิเคชันสำหรับการจัดตารางพนักงานพาร์ทไทม์ของร้านอาหาร
สร้างด้วย **Streamlit + PuLP + Python**

## 🧩 คุณสมบัติ
- กำหนดรายชื่อพนักงานได้เอง
- กรอกวันและกะที่ว่างของแต่ละคน
- กำหนดจำนวนพนักงานหลัก/สำรองต่อกะ
- กำหนดจำนวนกะสูงสุดต่อสัปดาห์
- จำลองกรณีพนักงานขาดและระบบเลือกสำรองอัตโนมัติ
- แสดงผลตารางทำงานในรูปแบบที่อ่านง่าย

## 🖥️ การใช้งาน
1. ติดตั้งไลบรารีที่จำเป็น  
   ```bash
   pip install -r requirements.txt
   ```

2. รันเว็บแอป  
   ```bash
   streamlit run app.py
   ```

3. เปิดในเว็บเบราว์เซอร์ที่ http://localhost:8501/
